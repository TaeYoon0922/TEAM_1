# ROLE02 STAR & 두괄식 분석 모델

## 1. 목적
자소서 답변 문장을 입력받아 STAR 구조와 두괄식 여부를 분석

## 2. STAR 요소별 언어 특징

| 요소 | 의미 | 언어적 패턴 | 주요 키워드 |
|---|---|---|---|
| S | Situation | 문제 상황, 배경, 맥락 설명 | 문제, 발생, 당시, 과정, 어려움 |
| T | Task | 역할, 목표, 책임 설명 | 역할, 담당, 목표, 필요, 과제 | ||실제 데이터 상으론 구분이 모호한 경우 다수
| A | Action | 실제 수행 행동 설명 | 분석, 개선, 설계, 비교, 수행 |
| R | Result | 결과, 성과, 변화 설명 | 결과, 향상, 감소, 달성, 해결, % |

## 3. 두괄식 정의
첫 문장이 핵심 역량, 성과, 문제 해결 경험을 요약하면 두괄식으로 판단한다.
