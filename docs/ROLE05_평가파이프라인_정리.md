# ROLE05 자소서 평가 파이프라인 — 보고서/발표용 정리

> 질문+답변을 입력받아 **질문 유형을 자동 분류**하고, 유형에 맞는 지표만 골라
> **점수 대신 고칠 수 있는 피드백**을 제공하는 파이프라인.

---

## 1. 목표

- 자소서 답변을 **7개 지표**로 평가하되, 최종 산출물은 점수가 아니라 **피드백**.
- 질문 유형(군집)에 따라 **적용 지표를 자동 선택**(불필요한 지표는 빼기).
- 질문과 동떨어진 답변은 **먼저 걸러내기**(게이트).

---

## 2. 전체 흐름

```
[질문 + 답변]
     │
     ▼
① 문항 적합성 게이트  ──(낮으면)──▶  세부 분석 중단 + "질문에서 벗어남" 안내
     │ (통과)
     ▼
② 질문 군집화 (SBERT + K-Means) → 6개 유형 중 하나
     │
     ▼
③ 군집별 지표 게이팅 (cluster_map.json) → 6지표 중 ON/OFF 결정
     │
     ▼
④ 켜진 지표만 분석 → 지표별 + 문장별 피드백 (점수 미노출)
```

---

## 3. 단계별 방법과 근거

### 3.1 질문 군집화 (SBERT + K-Means, k=6)
- **방법**: `ko-sroberta-multitask`로 질문을 임베딩 → K-Means(k=6).
- **k 선택 과정(정직하게)**:
  - Elbow: 곡선에 뚜렷한 꺾임 없음.
  - Silhouette: 모든 k에서 **0.02~0.05**(0에 가까움) → 데이터에 자연적 군집 경계가 약함 → **통계적 최적 k가 없음**을 확인.
  - 따라서 통계가 아니라 **균형도 + 해석가능성 + 활용 목적(지표 라우팅)** 으로 k=6 결정.
- **개선 효과**: 명사 TF-IDF 군집의 catch-all 쏠림 **43% → 20.7%** (SBERT 의미 임베딩으로 균형화).
- **근거 방법론**: Sentence-BERT(문장 의미 임베딩), Silhouette·Elbow(군집 수 진단).

### 3.2 문항 적합성 게이트 (키워드 + SBERT 하이브리드)
- **방법**: `점수 = 0.4 × 키워드중복 + 0.6 × SBERT코사인(질문↔답변)`. 임계값 미만이면 중단.
- **하이브리드 이유**:
  - 키워드 = **정밀도**(질문 요구조건을 그대로 충족했는지).
  - SBERT 코사인 = **재현율**(같은 뜻을 다른 말로 쓴 답변도 인정).
  - 실측: 키워드 0점이지만 의미상 온토픽인 답변(코사인 68)이 **오차단되지 않고 통과**. 오프토픽(코사인 8)은 그대로 차단.
- **근거 방법론**: SBERT 의미 유사도 + 희소(키워드)·밀집(임베딩) 신호 결합.

### 3.3 군집별 지표 게이팅
- **방법**: `cluster_map.json`의 `indicators` 배열로 6군집 × 6지표 ON/OFF.
- **설계 원칙**:
  - 글쓰기 공통(핵심주장 명확성·표현 명료성·자기표현 차별성·문장 완성도) → **전 군집 ON**.
  - 경험 구체성(STAR) → **경험을 요구하는 군집만**(문제해결·직무역량·협업).
  - 지원 적합성 → **직무·회사 연결이 핵심인 군집만**(지원동기·포부, 직무역량).

| 군집 | 핵심주장 | 경험구체성 | 지원적합성 | 표현명료성 | 자기표현 | 문장완성도 |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| 지원동기·포부형 | ✅ | ❌ | ✅ | ✅ | ✅ | ✅ |
| 문제해결·성과경험형 | ✅ | ✅ | ❌ | ✅ | ✅ | ✅ |
| 직무역량·강점형 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 성장과정·성격형 | ✅ | ❌ | ❌ | ✅ | ✅ | ✅ |

### 3.4 지표별 모델 연결 현황

| 지표 | 연결 모델 | 상태 |
|---|---|---|
| 문항 적합성 | relevance_detector + ko-sroberta 코사인(하이브리드) | ✅ 연결 |
| 핵심 주장 명확성 | KoSimCSE(BM-K/KoSimCSE-roberta), 규칙 폴백 | ✅ 연결 |
| 경험 구체성 | STAR 키워드 규칙(role02) | 🟡 규칙(전용 모델 없음) |
| 지원 적합성 | 직무 키워드 사전(job_fit_detector, 10직무군·457키워드) | ✅ 연결 |
| 표현 명료성 | hedge_detector(role03) | ✅ 연결 |
| 자기표현 차별성 | self_detector(role04) | ✅ 연결 |
| 문장 완성도 | — | ⛔ 미연결(맞춤법/가독성 모듈 부재) |

> **정직성 원칙**: 전용 모듈이 없는 지표는 가짜 휴리스틱을 붙이지 않고 **"미연결"** 로 표기하고 피드백·요약에서 제외.

### 3.5 임계값 보정 — *데이터 기반 시도와 그 한계* (핵심)
- **시도**: 라벨 데이터(`role05_match_dummy_300.csv`, manual_label=OFF_TOPIC)로 하이브리드 가중치·게이트 임계값을 **Youden's J / F1 / AUC** 로 산출.
- **결과**: AUC = **1.0000**, 최적 임계값 **T = 44** (F1=1.0).
- **그러나 이 숫자는 채택하지 않음** — 그 이유가 이 프로젝트의 방법론적 핵심:
  - AUC=1.0은 합성 더미의 OFF_TOPIC이 **지나치게 명백**해서 어떤 컷이든 완벽히 갈린다는 신호(= 임계값을 결정해주지 못함).
  - 실제 짧은 온토픽 답변은 하이브리드 28~51점 → **T=44면 정상 답변이 과차단**됨.
  - 따라서 더미 보정값(44) 채택 = **합성 데이터 과적합(끼워맞추기)** → 회피.
- **결정**: 명백한 동문서답(코사인 8 수준)만 막도록 **보수적 임계값 20 유지**, 가중치 0.4 유지.
- **재현 스크립트**: `scripts/calibrate_relevance_gate.py` (실제 라벨 데이터 확보 시 그대로 재실행).

## 5. 한계와 향후 과제 (정직하게)

- **합성 라벨 의존**: 게이트 임계값을 정밀 보정하려면 **사람이 라벨링한 실제 동문서답 Q-A 데이터** 필요. 현재 더미로는 임계값을 신뢰성 있게 못 정함 → 보수값 유지.
- **미연결 지표**: 문장 완성도(맞춤법/가독성 모듈 부재), 경험 구체성(전용 모델 없이 규칙). 후속 모델 연결 필요.
- **군집 분리력 약함**: 질문 임베딩의 실루엣이 낮음 → 군집 경계가 본질적으로 모호. 유형 분류는 "대략적 라우팅" 용도로 해석.

## 6. 참고 방법론 / 모델 (최종본은 원문 확인 권장)

- **Sentence-BERT**: N. Reimers, I. Gurevych, *Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks*, EMNLP 2019. — 문장 의미 임베딩/코사인 유사도.
- **Silhouette 계수**: P. J. Rousseeuw, *Silhouettes: a graphical aid to the interpretation and validation of cluster analysis*, J. Comp. Appl. Math., 1987. — 군집 수 진단.
- **Youden's J index**: W. J. Youden, *Index for rating diagnostic tests*, Cancer, 1950. — 이진 분류 컷오프 선택.
- **사용 모델(HuggingFace)**: `jhgan/ko-sroberta-multitask`(군집화·문항적합성), `BM-K/KoSimCSE-roberta`(핵심 주장 명확성).
- **데이터**: 잡코리아 합격 자소서 데이터셋(직무 키워드 사전 추출 출처), role05_match 더미 라벨 데이터.
