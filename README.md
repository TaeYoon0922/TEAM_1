# TEAM_1

자소서 문장을 붙여넣으면 두괄식, STAR, 모호도, 자기중심 4가지 지표로 자동 분석하고 개선 피드백을 출력하는 텍스트 마이닝 시스템입니다.

## ROLE 05 UI 실행

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

## 현재 구현 범위

- 자소서 입력 화면
- 분석 버튼과 종합 점수 출력
- 두괄식, STAR, 모호도, 자기중심 4개 지표 카드
- 지표별 막대 차트 대시보드
- 강점, 개선 포인트, 문장별 피드백 출력

## 모델 연동 예정

현재 `app/analyzer.py`는 ROLE05 UI 개발을 위한 mock/fallback 어댑터입니다. 실제 모델 구현이 아니라 화면 구성과 통합 형식을 확인하기 위한 임시 결과를 만듭니다.

- ROLE02: 두괄식 및 STAR 분석 모델
- ROLE03: 모호도 및 해지 표현 탐지 모델
- ROLE04: 자기중심 언어 비율 분석 모델
- ROLE05: Streamlit UI, 대시보드, 모델 출력 통합

ROLE02~04 모델이 완성되면 `analyze_cover_letter()` 내부에서 각 모델의 예측값을 받아 같은 결과 형식으로 반환하도록 교체하면 됩니다.
